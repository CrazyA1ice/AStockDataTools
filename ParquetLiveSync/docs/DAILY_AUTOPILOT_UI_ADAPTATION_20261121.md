# Daily Autopilot S2：两套真实 Windows 界面统一展示每日运行健康

## 目标
用户明确要求不再每天手动排查财务历史冲突，同时软件 UI 随新自动更新方案同步变化。现有 `market_update_dashboard.py` 是操作界面，可手动触发原20:05管线，现有 `market_center_v2e_selected_ui.py` 是七页设计预览/只读核验界面。两者不能显示互相矛盾的状态。

## 本次只读UI更新
1. 共用 `market_daily_autopilot_view.py`，调用已开发的 `market_daily_autopilot_shadow.inspect`，仅从已存在的正式回执和财务账本读取SHA核对后的状态。没有QMT/Parquet读写、计划任务创建、下载或自动重试。
2. 界面上 **将原始PARTIAL回执与日常续扫健康分开显示**。例如 2026-11-21 历史回执：四阶段exit0，财务159只、待遍历5201只、待审85只，原始数据质量PARTIAL/跨源UNVERIFIED，新的健康分类ROUTINE_CONTINUATION。只能说“暂无已证实的执行故障”，不能说“全部数据完整”。
3. 两个GUI均展示：最近一次任务的日期/执行状态、财务本轮处理/待遍历/待审、数据质量和跨源认证、待处理建议、**估值派生层（总市值/PE/PB）尚未启用**。正式调度状态不直接被覆盖，老日志与原始状态仍保留。
4. 状态源不存在/损坏时显示 `UNKNOWN`，不能以空记录假装绿色。UI完全没有自动恢复、QMT下载或修复按钮；现有操作界面手动补更仍受原写锁及原时间安全窗口控制。
5. 七页式中心继续7页固定导航：首页为一屏紧凑摘要，不新增冗长日志或第二滚动容器。状态数据来自用户本机，不在PR/日志里公开原始财务数值。
