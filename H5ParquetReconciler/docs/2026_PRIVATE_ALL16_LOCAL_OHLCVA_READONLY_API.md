## 新的本地OHLCVA接口

`tools/query-private-2011-2026-all16-ohlcva-local-readonly.py`提供 `read_local_bars(version_safe,version_sha256,symbol,start,end,allow_private_values=True,max_candidate_rows=3000000,max_result_bars=31)` Python API。若无显式`allow_private_values=True`立即拒绝读取。要求规范A股代码、1—31日窗口、最多31条返回记录（超出即拒绝，不返回部分结果），且与之前一样每次验证SHA绑定16年私有版本及选中年度Manifest/SQLite和所有被选中的Parquet分区完整SHA。覆盖查询默认仍只读4个键列，**本地API明确授权后**才会读取真正OHLCVA六个Float64列，按原source_symbol+时间戳重新归一化并逐条比较购买/H5来源；随后必须通过SQLite股票日唯一键和来源分类数量检查才会返回任何结果给调用者。

API结果`{"bars":[实际本地行字典...],"safe_summary":{脱敏聚合}}`仅存在调用进程内存，用户自己在本地使用数据时须遵守购买数据许可。命令行模式`--verify-local-values-only`即使加载真实六个价格/量/额列，也**只写`reports/*.json`脱敏汇总**，只输出行数/来源/耗时，不打印/导出股票代码、确切日期、价格、成交量、成交额或单行行情。禁止将真实行情和private文件放入GitHub、聊天或外部插件。H5补缺的单位/舍入语义仍未经认证，报告会保持false；这不是正式生产查询授权、自动市场合并或H5镜像。
