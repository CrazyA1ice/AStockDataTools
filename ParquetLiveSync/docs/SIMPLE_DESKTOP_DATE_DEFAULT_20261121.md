# AStockDataTools：单一三页数据管理中心

统一菜单仅显示：数据总览、下载/更新、异常与日志。正式原有20:05计划任务、互斥锁、历史快照、备份、财务待审与既有自动下载流程均不改动。当前只在Draft提交软件界面改版，尚未在用户Windows现场运行。

日期默认：
- 开始日期 = 结束日期 = 最近一个已经结束、允许盘后更新的A股交易日。
- 优先通过隔离子进程在9秒预算内只读查询QMT上海市场交易日历（get_trading_dates），返回日期必须不晚于北京时间20:05盘后截止。不是靠工作日加减或手工节假日清单推断。
- QMT暂时断开，则使用本地已提交1min行情账本中的最后实际交易日作保守回退，并提示该日可能落后市场最新日。两者都无证据则留空，不默选假日期。
- 用户手工改过开始或结束日期后，QMT迟到的回执不再覆盖用户输入。可自定义更早时间段，结束时间不能超过盘后候选安全截止。

界面减法：
- 数据总览：八周期的已记录日期索引各自独立显示起止日期；板块、除权、财务缺少可信独立覆盖范围时显示“未核实”。多源验证状态不以主任务exit0推断通过；错误解释可点击并查看日志。
- 下载/更新：可选择增量/重新下载并比对、全市场/自选股票、起止日期及四类数据。所选范围先做纯预览。原正式执行器并不支持任意股票+日期写入，所以指定范围执行按钮禁用，不能宣称这次选择已经执行。原有按游标全市场续更作为独立按钮保留，走原手动确认与写锁规则，绝不会偷换用户在上方选定的日期范围。
- 异常与日志：显示四阶段数据验证、跨源结果和最近私有日志，可选中查看、打开完整日志，非必要的技术说明和七页研究流程不放在默认主入口。

原七页只读核验工具仍保留在仓库供高级检查，但默认启动器在Draft里改指向三页主窗口。估值/PE/PB派生尚未实现，因此不显示假数据表。将来必须为指定范围写入另建有完整版本备份、二次确认、对账和互斥锁的执行器后才能开放该按钮。
