# Market Center V2G5：截断观察清单的显式披露（2026-11-21）

## 起点

从 V2G4 `d651d23a62e8056ef16506cb561710888884dc8c` 派生。本阶段仅修补只读核验结果页的证据可见性问题。V2-B 控制器对观察结果有 `rows[:600]` 的展示上限，而原始内存 JSON 仍包含完整观察列表。若某次受限范围返回超过 600 条观察，用户可能误以为可见表格就是完整清单。

## 更改

- 使用已通过 V2G2 保守解释门禁的 `summary["observation_count"]` 与当前表格实际条数比对，不重新扫描、下载或打开任何行情源。
- 当原始报告包含更多观察时，在既有证据摘要后补充「表格仅展示 X/Y 条观察」和「展开原始 JSON 查看完整清单」；在核验下一步提示中说明不能用可见行数推断全量状态，应缩小范围逐条复核。
- 当观察全部可见或报告为空，不添加截断说明；重复渲染不会重复追加证据提示。
- 原始证据、结果排序、首条默认选中、只读约束和自动修复 disabled 状态不变。

## 测试和发布

新增4项独立 Tk 合成回归：截断披露及原始列表保留、完整列表不误报、重复刷新不重复提示、空结果不宣称完整。无真实 QMT、付费行情及市场文件操作。基于 V2G4 预计 308 项的基数，现预计 312 项测试方法，**未运行 Windows 全量回归，不能宣称通过**。

建议使用独立 worktree，按本 PR 的精确提交 SHA 固定执行测试，再于真实 Windows 界面复核两个股票日和一次 >600 条合成显示。此 PR 保持 Draft，不合并 main，不部署，不执行正式数据修复。
