# 2011—2026年全量日线双源核对：第一轮实测与股票范围修正（2026-10-25）

## 数据来源与范围

用户本机运行AStockDataTools的 `--periods day` 只读程序并提交：
- `h5-parquet-day-audit.json`：16年全部标记scan_complete=true；没有文件读取、Schema、未知Parquet代码或批次内重复键错误；
- `h5-parquet-day-audit.md`：年度统计和最多24个例子。
原数据位于用户D盘，付费Parquet/H5没有上传本仓库。这只是上传聚合报告的研究总结，不含原始行情价格、成交额和成交量。

## 两个明确存在的系统性混淆项

**1. A股股票与指数/其他品种混在一个分母**

`h5_only_examples` 反复出现SH000001、SH000002等指数代码；不少年度全年的H5独有数在每个交易日稳定偏高。这些并不是需要从H5拷贝到A股股票Parquet的股票数据。2026年甚至出现BJ899050等候选指数/其他品种，不能仅因两个字母表示交易所就认定股票。

新代码添加 `--universe a-share-candidate` 初步过滤沪/深/京代码前缀、B股、常见指数及过渡前的京市后缀回溯。旧统计保留为全代码来源差集，新的股票候选审计必须用新输出文件名单独重算。该候选分类并非完整的证券上市主数据。

**2. 北交所历史代码回溯与旧精选层证券**

例如旧报告2015年 `BJ920961` 被列为Parquet独有，年份远早于北交所2021年11月15日开市，属于高风险的历史证券代码归属问题。新候选筛选保守排除2021年及以前整个BJ代码集，避免将新三板股票旧历史直接当成北交所上市日线；此举同时会略去真正的2021年末北交所行情，因此无法当作最终完整股票清单。

## 新旧数据时间范围

- 全品种H5日线：2011-01-04 至2026-10-13；
- Parquet日线：2011-01-04 至2026-09-30；
- Parquet日线并非较H5拥有更早的**全库最早日期**，但在某些单股/交易日拥有H5不存在的记录。
- 2026-10-08、10-09、10-12、10-13报告中的H5独有各为7,776、7,785、7,795、7,797条，合计31,153条。这4日确实在Parquet2026-09-30的报告截止时间以后；其余大量H5独有出现在重叠时段或非股票代码，不能仅凭全库最新日期认定H5全新尾部已经完整。
- 截至2026-10-25，H5本身的日线报告只到10-13，未能证明10月14—23日行情已经采集入库。源数据还不是“截至今天全部最新”的证明。

## 量价冲突的集中度

- 16年87,170行重叠量价冲突中，2026年独占68,575行（约78.7%）。
- 2026-07-16当天即有5,551行量价差异，和先前小样本H5当天不完整/异常观察相符，但不能直接断言55xx个样本全是同一个采集bug。
- 2026年9月若干日期也有1,100—1,395行量价差异，提示需要检查近端数据的完整性、金额、成交量口径及是否系统性批量不一致。
- 2011—2025年主要冲突是成交量或成交额；一些年份有少量OHLC字段差异。2026年有4,980行价格差异，值得按日期/板块单独分析。
- 单纯旧H5 7月16日午间异常/来源采购新旧并不能证明Parquet是绝对正确，**冲突键必须保留审计状态，不可自动覆盖**。

## 新一轮可直接运行的安全验证

在AStockDataTools仓库根目录：

```powershell
git pull --ff-only origin main
.\.venv\Scripts\python.exe -m unittest discover -s H5ParquetReconciler\tests -p "test_reconcile_local_a_share_h5_parquet.py" -v
.\.venv\Scripts\python.exe H5ParquetReconciler\tools\reconcile-local-a-share-h5-parquet.py "D:\stock" --years 2025 2026 --periods day --universe a-share-candidate --read-only --scratch "D:\AStockAuditScratch" --out "D:\AStockAuditReports\h5-parquet-day-equity-2025-2026.json"
```

如果测试和试跑成功，另换未使用的报告文件名运行2011—2026年的 `--universe a-share-candidate` 日线审计，再比较按证券类型修正后的实际A股候选差集。此时年度H5全为空的分钟段仍仅有Parquet年度footer估算，不能把候选行数当作逐条确认的Parquet独有股票K线。

## 进入并集前仍必须完成

1. 区分A股候选证券、指数、ETF、B股、历史精选层和历史更名/复权。用交易所/供应商真实证券基础资料认证，不仅用代码前缀推断。
2. 对Parquet跨Arrow batch的重复证券-时间键执行唯一性检查，归一化后重新计算三类行数守恒。
3. 区分真正2026-09-30之后尾部H5独有，与2026-01—09间代码覆盖、价格/量额冲突；不直接合并。
4. 逐周期独立完成5min、1min覆盖和单位、开盘分钟/午间标签验证。日线结论不能直接推广分钟线。
5. 输出并集库时只使用新目录，保留冲突追溯、源文件哈希及可逆版本切换。

当前源数据仍保持只读；没有进行两格式互转或生成并集库。
