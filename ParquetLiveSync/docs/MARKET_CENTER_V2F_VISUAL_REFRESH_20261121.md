# Market Center V2F 视觉重设计 · 2026-11-21

## 用户反馈
用户已展示 V2E4 在 1332×882 Windows 桌面上的七页版首页，明确表示“这个太丑了”，希望下一阶段实质提升整体视觉，而不是再反复改卡片高度与滚动条。并要求后续 Windows PowerShell 命令尽可能合并成单条单行，方便复制。

## 设计方向
**V2F 保留已经确认的七页功能架构，但替换 Tkinter/ttk 视觉语言。** 不新引入第三方UI依赖，优先使用已经安装的Tkinter内建clam主题，在现有 worktree 可以直接启动；不绘制不能点击的图片作为假界面。

### 全局
- 采用低饱和蓝灰配色：背景 #F5F7FB、正文 #31445E、深色标题 #182B46，侧栏 #12233D；主强调色 #2469B6。
- 侧栏导航加大可点击区域、统一选中状态、减少纯深蓝压迫感；标题字重与页面字号层级更加统一。
- 全局树表行高适当加大，表头从硬描边调整成浅灰、无凸起；按钮使用统一扁平样式，优先级清晰，保留 Windows Tk 可访问性。
- 沿用现有实际功能：七页导航、三步更新/核验预览、核验明细表与原始证据、故障及QMT即时连接检查、最近日志检索、八周期只读卡、设置只读说明。

### 首页
- 移除层层嵌套的原生边框 LabelFrame，改为白底扁平 KPI 卡片、左侧独立核验状态/2×2阶段单元、右侧可信变化与常用操作；底部是仅占一块的“待处理事项与下一步”。
- 改进文字对比与字号，让 KPI 数字比辅助说明醒目；运行状态根据实际执行结果显示，数据核验和跨源抽样三类状态独立着色。未认证状态不标绿。
- 故障摘要左侧标记由真实 ERROR/WARN/INFO 决定；无证据时中性，绝不会因为没有异常记录而宣称数据已经完整。
- 首页没有外层 Canvas/Scrollbar；高密度长日志和证据仍留在各自页面滚动。较窄窗口继续动态换行，不能隐藏任何需要确认的安全提示。
- 保留原先动态 StringVar/按钮属性（cards/card_widgets、stage_labels/stage_widgets、validation_vars、fault_title_view 等），复用后端原有回执与颜色更新；QMT探测必须用户主动点击，财务版本检查只读，一键重试始终禁用。

## 安全边界
这是一项**纯视觉更新**，没有修改/安装/触发单一20:05 Windows自动任务，没有更新 QMT worker/写锁，不连接或下载历史行情，不清理金融账本或财务历史版本，不改任何 Parquet 文件。所有财务恢复与行情补缺仍遵守原先的独立来源、日历、版本哈希和事务审批要求。

## 验收
基线 V2E4 原有 235 个 unittest 测试方法（其中V2E2～V2E4新增测试是否通过以本地实际结果为准），新增 5 项针对全局视觉一致性/扁平首页/真实错误等级着色/原接口保留的合成测试，共 **240 项测试方法**。GitHub静态字符/括号平衡检查通过，并非 Python编译或 Windows Tk实机运行。下一步请用户在独立detached worktree运行一行 PowerShell 获取+离线测试+打开GUI。

需要在真实 1332×882 和更大显示器检查：七页能正常切换、首页不出现整体滚动条、KPI与状态对比明显、四阶段和故障提示层级清晰、日志与长证据内部滚动仍可用、一键重试持续禁用。完成截图反馈前保持Draft不合并生产。
