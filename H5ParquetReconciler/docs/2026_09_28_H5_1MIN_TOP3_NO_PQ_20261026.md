- **成交量按候选H5×100换算后，三只股票全天、各自上午24根以及下午24根，Parquet/H5成交量净差都正好=0%**；但逐根毛差占全天成交量比例依次为0.928496%、0.561701%、0.717788%；同日三只的相邻量差相关系数分别约 -0.482、-0.455、-0.446。上午、下午交易段分别零净差支持段内重新分配假说，但**不是最终来源正确性证明**。

- **Parquet行组代价已经量化**：尽管最终只筛选144根五分钟K线，上次定向扫描仍解码47个行组的5,685,792行数据！因此下一步不得无必要再次调用Parquet文件读取。

## 二、本轮新增H5-only验证工具

`tools/inspect-h5-1min-top3-no-parquet.py`仅从此前已经完成的×100分时报告自动读取真实三个股票代码，**只读HikyuuData/sh_1min.h5（和sh_5min.h5）中这三个股票的2026-09-28有界时间窗口**。绝不调用Parquet加载函数，不需要Parquet原始股票OHLCV也能输出一次新的诊断。

每只股票用上一轮已确认的H5 5min 48根K线做参照，对H5 **1分钟线的两种时间标记约定分别测试**：
- `minute_end_label`：5根1min结束时间为五分钟结束点减4分钟至结束点；
- `minute_start_label`：5根1min开始时间为结束点减5分钟至结束点减1分钟。

只有**确实存在全部5个时间标签**的窗口才计算聚合OHLC、量和额；缺一分钟就记为`incomplete_windows`，不伪报“价格错误”。每个约定再与H5 5min的候选原始成交量×100比较两个1min成交量因子：`1`（一分钟值本身视作股）、`100`（一分钟值也视作手）；这两者目前都只是候选，**不能推断一分钟文件一定与五分钟文件相同单位**。零成交量窗口单独计数且**不得用于支持单位因子**；非零窗口匹配数单列。

按整个交易日、上午24根、下午24根给出：可聚合窗口数、不完整窗口数、OHLC全部符合既有容差的根数、逐字段符合计数、成交额一致计数、不同1min成交量因子候选符合计数及有效非零分母。**不导出任何原始OHLCV、具体市场价格或供应商文件记录**。

数据缺失会报告`not_verifiable_no_one_minute_data`或`not_verifiable_no_complete_one_minute_windows`。同一证券1min重复标签报告`not_verifiable_duplicate_one_minute_keys`，不作伪精确对比。即便1min与H5 5min吻合，它们可能共享相同上游行情，**不能称已获得真正独立第三方来源认证**，且此次没有再对PQ五分钟逐根复扫。任何命令都保留`safe_to_automatically_union=false`。

新增`tests/test_inspect_h5_1min_top3_no_parquet.py`**6个纯合成测试**，覆盖两种标时、两种成交量倍率、上午下午各24根、部分分钟缺口、无一分钟文件/重复键、H5 5min根数改变以及真实来源报告身份验证。

## 三、Windows运行命令：只读H5分钟文件，不读Parquet

在仓库根目录：

```powershell
git pull --ff-only origin main
.\.venv\Scripts\python.exe -m unittest discover -s H5ParquetReconciler\tests -p "test*.py" -v
.\.venv\Scripts\python.exe H5ParquetReconciler\tools\inspect-h5-1min-top3-no-parquet.py "D:\stock" --date 2026-09-28 --baseline-report "H5ParquetReconciler\reports\h5-parquet-5min-x100-2026-09-28-top3-sessions.json" --read-only --out "reports\h5-1min-2026-09-28-top3-no-parquet.json"
```

输出`H5ParquetReconciler/reports/h5-1min-2026-09-28-top3-no-parquet.json`。只上传新JSON（如果已存在则选择新输出文件名）；不要上传付费市场文件。如果原先的baseline存放位置不一样，`--baseline-report`只需提供实际已存在的路径。

**后续研究决策：** 若H5 1min有足够完整的五分钟窗口，且某个1min时标/量纲组合高度吻合H5 5min，则说明H5同供应商周期内部计算是可复核的，仍不能断言PQ必然错误；若仅某一种时标贴合，有理由进一步研究PQ取窗方式。若无1min则保留现有段内重新分配的**候选**归因，转去北交所113根仅价格残余进行真实证券定位，而不是扩大至全部行情数据。
